# Netflix_EDA_Project

## 📌 Objective
Analyze Netflix content data to identify trends in ratings, genres, and release patterns.

## 🧹 Data Cleaning
- Filled missing values in categorical columns using mode
- Handled null values in director, cast, and country columns
- Removed duplicate records
- Dropped unnecessary columns

## 📊 Visualizations Used
- Countplot
- Barplot
- Histplot
- Boxplot
- Scatterplot
- Heatmap

## 🔍 Key Insights
- TV-MA is the most common rating — Netflix targets mature audiences
- Movies outnumber TV Shows by more than 2x
- Content exploded after 2015, peaking in 2019
- International Movies and Documentaries are the top genres
- Most content is recent — majority released after 2010
- Old classic titles exist as outliers (pre-1980)
- 
## ✅ Conclusion
Netflix focuses heavily on recent, mature-rated content with strong investment in international movies and documentaries to attract a global audience.
